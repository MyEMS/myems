## 一、系统介绍

### 1.1 系统定位

MyEMS 是利用云计算、物联网、大数据、人工智能等技术构建的综合能源服务平台，覆盖能源购买、消费、转售的全过程与用能系统设计、交付、运维的全周期，提供以终为始、全量化、无死角的能源管理方案。它帮助业主全面掌握能耗情况、避免管理漏洞与技术缺陷、实现高效用能与品能平衡，并履行社会责任。

系统参照 GB/T 23331-2020（等同采用 ISO 50001:2018）能源管理体系设计，记录能源数据、对比不同时段、生成能耗与碳排放报表；但**不代替组织自身的 ISO 50001 管理体系，也不代替认证审核**。

系统内置大数据驱动的人工智能算法平台，在能耗预测、运行策略评估、用能事件建模、运行异常诊断等方面提供超越经验的计算能力；并针对冷站等重点用能系统提供更精细化的设计、调适与运行管理方案。系统已积累上千个项目案例，代码以 MIT 协议开源。

### 1.2 系统优势与核心特性

**三大优势**

- **免费开源**：代码以 MIT 协议开源；群内技术支持不收费，每月持续更新。
- **多能源一体**：电、水、气、冷、热放在同一套系统里采集、分析和出报表，覆盖建筑、工厂、商场、医院和园区。
- **从能耗到碳排**：对照历史用量，生成能耗、费用和碳排放报表；光伏、储能和微电网可按项目选配。

**核心特性**

- **当下就能看见**：电、水、气、冷、热进同一块看板，当前负荷和用量马上能看到。
- **对照历史找浪费**：按小时、日、月、年做同比和环比，哪里多耗一眼可见。
- **用量费用一套账**：用量、费用和碳排放用同一套表计计算，每个数字都能回到具体计量表。
- **按对象拆开看**：同一份数据可按空间、设备、车间、门店和租户拆开查看，分摊无需手工计算。
- **表计直接接入**：支持 Modbus、BACnet、西门子 S7 和 OPC UA；离线表和 Excel 也能导入。
- **汇报直接用数**：仪表盘、能流图和 Excel 导出都现成，汇报与核查直接使用系统数据。

### 1.3 系统构成与数据流（简述）

系统由**后台管理端（myems-admin）**与**前端应用（myems-web）**两部分组成。你日常使用的是网页端 myems-web，它负责能耗数据的图表展示与分析（React，支持桌面与移动端浏览器），页面报表可导出为 Excel/Word/PDF；myems-api 为其提供数据接口。

数据从现场到报表的链路为：**计量表数据 → 数据采集 → 数据清洗 → 数据规范化 → 数据汇总 → 数据分析 → 数据可视化**。报表为请求级生成，因此**报表看到的最新数据通常滞后一个时段**，这是设计节拍而非故障。

### 1.4 适用场景与使用边界

**适合**：一般建筑、商场、酒店、商业综合体、医院、学校、写字楼、机关单位、体育场、景区、地下管廊、工厂、矿山、港口、企业园区、乡镇、城市等各种用能单位；单一主体的私有化部署；内网或离线环境；有租户、门店、车间等多维核算需求；点位规模千级至万级，管理周期为日、月、年；需要二次开发或与自有系统集成。

**不适合（边界之外）**：

- 需要秒级闭环控制或联锁保护（系统为轮询采集 + 小时级批处理）；
- 用于贸易结算或计量检定（系统未做计量法制认证，精度责任在表计）；
- 多租户 SaaS 或超大规模集中部署（无组织级行级隔离，单库写入有瓶颈）；
- 需要复杂组态画面与工艺动画（系统组态工具深度有限）。

**使用提醒**：报表数据通常滞后一个时段；若要更实时，请使用「计量表实时分析」或「设备实时监控」。

## 二、核心概念（使用前必读）

### 2.1 关键术语

| 术语 | 含义 |
| --- | --- |
| 能源分类 | 按能源种类划分的计量对象，如电、自来水、天然气、冷热水、蒸汽、二氧化碳；承载单位、千克标准煤（kgce）与千克二氧化碳排放（kgCO₂e）两项折算因子 |
| 能耗分项 | 按用途划分的能耗归属，如空调用电、动力用电、照明用电；挂接在能源分类之下 |
| 空间 | 组织能源数据的层级载体（园区—建筑—楼层—房间），通过父指针构成树，是绝大多数报表的筛选起点 |
| 计量表 | 能源计量的最小业务单元，绑定一个能源分类；另有**离线表**（由录入或导入取值，而非轮询采集）与**虚拟表**（用公式根据其他计量表计算）两类派生形态 |
| 数据点 | 数据源上的一个地址（如一个 Modbus 寄存器或 BACnet 对象），含累积量、瞬时量、状态量、文本量等类型；系统不设数据点数量许可上限 |
| 数据源 | 一组同协议、同连接参数的采集目标 |
| 设备 | 用能设备台账，可绑定计量表、数据源、参数与指令 |
| 组合设备 | 把多台设备放在一组（如制冷站），按系统口径核算能源、碳排、费用、产量、收入、能效、负荷 |
| 租户 / 门店 / 车间 | 挂在空间树上的业务子类，分别对应租赁主体、零售或连锁门店、生产楼层（车间） |
| 网关 | 现场采集程序所在的计算机设备，用于监控采集链路状态 |
| 成本中心 | 费用归集维度，绑定费率与碳排放因子用于成本与碳排核算 |
| 工作日历 | 区分工作日（生产时间）与非工作日，用于单位产品能耗等 KPI 与浪费识别 |

### 2.2 对象归属链

系统的领域模型核心是一条「归属链」：

```
数据源 → 数据点 → 归属 计量表 或 设备
计量表 → 绑定 能源分类；归属 空间；可挂 上级计量表（构成总分表树）
空间 → 通过父指针构成树；树上再挂 门店、租户、车间
组合设备 → 聚合多台设备 + 计量表
基础字典（能源分类、能耗分项、成本中心、电价、联系人、产品）被上述对象以外键引用
```

主要绑定关系：

- 数据点 → 计量表 → 空间/租户/门店/车间/设备/组合设备；
- 能源分类 → 能耗分项 → 计量表；
- 能源费率 → 成本中心 → 计量表/空间/设备；
- 碳排放因子 → 成本中心 → 计量表/空间；
- 工作日历 → 空间/租户/门店/车间；
- 指令 → 计量表/设备/组合设备/空间/储能集装箱等。

### 3.3 各功能板块说明

**总览（Dashboard）**：首页仪表盘，集中展示关键能耗、成本、碳排指标。

**空间数据**：以空间树为起点，查看各层级（园区/建筑/楼层/房间）的能耗、成本、碳排、产出、收入、效率、负荷、统计、环境监测与产量。适合"按区域/组织看总量与对比"。

**设备数据**：以设备台账为起点，查看设备用能与产出，支持设备效率分析、设备台账、设备实时监控、批量分析与对比。

**计量表数据**：最细颗粒度的计量视角。提供能耗/碳排/成本/趋势/实时/节能/计划/预测分析、**总分表平衡分析**（比较一块总表与它下面的分表，查看总量与分量的差额）、批量分析、对比分析、计量表台账、电能质量分析；并包含**虚拟表**（用公式根据其他计量表计算能源）与**离线表**（数值由录入或导入得到）的全套分析页面及离线表数据录入。

**租户数据**：按租赁主体维度统计能耗与费用，提供租户账单，用于对账与分摊。

**门店数据**：按零售/连锁门店维度统计。

**车间数据**：按生产楼层维度统计，配合工作日历与产量数据可做单位产品能耗分析。

**组合设备数据**：按用能系统维度（如制冷站）统计输入与输出，评估系统级转换效率（如 COP）。

**辅助系统**：

- 能流图：用桑基图展示能源在系统内的流向、分配与转化效率，用于发现跑冒滴漏与能源平衡校验。
- 配电系统：展示配电网络单线图与回路实时电气数据，用于负荷分析、过载预警与容量分析。

**工单管理**：维修记录、巡检记录、安装记录。

**知识库**：集中存储设备说明书、能源审计报告、运维 SOP、政策文件等资料，可按名称检索与下载。

**工具**：电缆选型工具、JSON 验证工具、Modbus 报文解析工具、能量单位换算工具。

**高级报表**：按模板定时生成并邮件分发报表。

### 3.4 报表页通用操作

大多数报表页的操作方式一致：

1. 在顶部选择**对象**（空间/设备/计量表/租户/门店/车间/组合设备）；
2. 选择**时间范围**与**时间粒度**（小时/日/月/年）；
3. 选择**能源分类**或**能耗分项**；
4. 选择**比较方式**（同比、环比、自选两个时段对比、或不做对比）与基准期；
5. 查看图表与表格，必要时点击**导出**按钮生成文件。

计量表能源报表通常包含报告期合计、基期合计、吨标准煤、吨二氧化碳、趋势、相关参数与明细。导出为服务端生成的**真实 xlsx / Word / PDF**（内含表格与折线图、柱状图、饼图），**不是 CSV**。

- 同一实例里的不同场所按空间树组织，而不是各自一个数据库。

## 四、常见操作问题（FAQ）

### 4.1 报表与数据

- **报表数据为什么不显示最新时刻的数值？** 系统采用"采集分钟级、规范化/清洗/汇总小时级、报表请求级"的节拍，报表数据通常滞后一个时段；需要更实时可看「计量表实时分析」或「设备实时监控」。
- **怎么看总分表对不上（总表大于分表之和）？** 用「总分表平衡分析」查看差值率；差值率超阈值应追查未计量回路、表计故障或绑定点位错误。建议每周做一次总分表平衡检查。
- **电价改了，历史成本数据会变吗？** 不会自动变。成本与碳排是能耗的线性变换，电价或因子调整后，历史数据需**按时间段重算**派生层才会更新。
- **异常表计读数会怎样处理？** 清洗会检查超出物理范围的值、时段内缺口、换表或通信故障后累计读数回退等情况；部分值被修正，部分被标记并排除在后续汇总之外。
- **计量表能源报表里有什么？覆盖哪些能源品种？** 可含报告期合计、基期合计、吨标准煤、吨二氧化碳、趋势、相关参数和明细，结果可导出 Excel。常见品种为电、水、气、冷、热及二氧化碳。

### 4.2 虚拟表 / 离线表 / 总分表等对象

- **什么是虚拟表？** 用公式根据其他计量表计算能源；可报表其能源、二氧化碳、费用和对比。
- **什么是离线表？** 数值由录入或导入得到，而不是轮询采集；可报表其能源、二氧化碳、费用和批量分析。
- **什么是总表和分表平衡？** 把一块总表和它下面的分表放在一起比较，用来看总量和分量的差额。
- **门店 / 车间 / 组合设备是什么？** 门店是零售或连锁店对象；车间是生产楼层对象；组合设备把多台设备放在一组（如制冷站），报表其能源、碳排放、费用、产量、收入、能效和负荷。

### 4.3 系统会把数据发到外部吗？

系统本身不向外发送数据，唯一例外是**启用 AI 分析时**会把聚合数据提交给模型服务商（DeepSeek / OpenAI）。涉及敏感数据、涉密环境或有数据出境限制的项目，应关闭外部模型调用。AI 结论不掌握现场工况、设备状态与工艺约束，**必须人工复核**后才能进入改造决策；涉及投资的建议应由专业人员出具独立方案。
